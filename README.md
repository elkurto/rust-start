# Learn Rust 2025

### Build and Run A Rust Project

```bash

# 1. create a project
cargo new hello_rust_proj
cd ./hello_rust_proj

  # here's the directory structure
  # hello_rust_proj/
  # ├── Cargo.toml
  # ├── src
  #      └── main.rs# here's the directory structure
  # hello_rust_proj/
  # ├── Cargo.toml
  # ├── src
  #      └── main.rs

# 2. build the project
cargo build

# 3. run the project
./target/debug/hello_rust_proj

  # output:
  # hello world

```
